# Laravel Essentials Documentation

Laravel Essentials bundles a set of opinionated Laravel defaults ("configurables") and a set of Domain Driven Design (DDD) scaffolding commands into a single installable package.

- [Configurables](configurables.md) — the sensible defaults applied on boot, and how to add your own.
- [Domain Driven Design](domain-driven-design.md) — the `ddd:install` and `ddd:make` commands.
- [Configuration Reference](configuration.md) — every `config/essentials.php` option.

See the main [README](../README.md) for installation instructions.
